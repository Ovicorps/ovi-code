    Using the TUI¶

    The chat screen contains an output panel for conversation and tool activity, and an input panel with a multiline Vim-style prompt editor. The highlighted panel title indicates keyboard focus.

    Insert mode¶

    Key Action
    Characters Insert text
    Enter Insert a newline
    Tab Insert four spaces
    Arrow keys Move the cursor
    Home / End Move to the start / end of the line
    Backspace / Del Delete text
    Esc Enter Normal mode

    Normal mode¶

    Key Action
    H / J / K / L Move left / down / up / right
    W / B Move forward / backward by word
    0 / $ Move to the start / end of the line
    G G / Shift+G Move to the first / last line
    I / A Insert before / after the cursor
    Shift+I / Shift+A Insert at the start / end of the line
    O / Shift+O Open a line below / above
    X Delete the character under the cursor
    D D Delete the current line
    Y Y Copy the current line
    P / Shift+P Paste after / before the current line
    Enter Send the prompt
    Ctrl+W Switch between input and output
    Z Minimize or restore the input panel
    S Open Settings
    T Cycle the selected technique
    C Clear the visible transcript
    Q Quit

    The internal line clipboard is shared by the prompt, tools.md, and skills.md editors.

    Output navigation¶

    Press Ctrl+W in Normal mode to focus the output panel.

    Key Action
    J / K Scroll down / up
    G / Shift+G Jump to the top / bottom
    Ctrl+W Return to the input panel

    The application shortcuts S, T, C, and Q remain available while output is focused.

    Settings¶

    Press S from Normal mode. Settings are organized into four tabs:

    Tab Contents
    Model Provider account, model, reasoning effort, and provider API key
    Agent Technique, execution limits, temperature, and instruction editors
    Appearance System, dark, light, and plain themes
    Shortcuts Chat and Settings keyboard reference

    Use Tab to move between controls (or cycle a focused list) and J / K or arrow keys to change list selections. Press Enter to activate a focused button, or I / A before typing in a text field.

    Save changes applies the configuration to the next turn. Cancel, Q, or Esc from Normal mode closes Settings without applying the form.

    Project instructions¶

    OVI-CODE reads three optional Markdown files from the workspace root:

    File Purpose
    agent.md Project persona, conventions, constraints, and hard rules
    tools.md Additional guidance for using tools
    skills.md Reusable recipes and project-specific capabilities

    Use another directory when instructions should live outside the workspace:

    ovi-code \
  --workspace ~/Projects/my-project \
  --agent-config-dir ~/Projects/my-project/.ovi-code

    Instruction files are reloaded at the beginning of every turn. Settings provides built-in editors for tools.md and skills.md; use S to save and Q to cancel from those editors.

    Privacy and session data¶

    • Provider keys are stored in ~/.ovi-code/config.json unless supplied through OPENROUTER_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY, or XAI_API_KEY.
    • Chat history is not persisted to disk.
    • Clearing the transcript with C does not clear model conversation context.
    • Requests, instructions, and file contents returned by tools are sent to the selected provider. OpenRouter may route them to a separate model provider.
